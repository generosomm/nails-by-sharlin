# Nails by Sharlin

A minimalist, responsive marketing website for Sharlin Camille Albino's nail services. Built with HTML, CSS and vanilla JavaScript, with glossy sculptural nail swatches created entirely in CSS.

## Run locally

From this directory, run `python -m http.server 4175`, then visit `http://localhost:4175`.

## Features

- Responsive layout, keyboard navigation and reduced-motion support.
- Interactive color inspiration in berry, rose, sage and pearl.
- Service prices from the supplied poster: manicure ₱100, pedicure ₱100, foot spa ₱200, gel polish ₱250.
- Service selection creates a prefilled SMS inquiry. SMS opens the visitor's installed messaging app; it does not automatically send a message or confirm an appointment.
- Telephone link, copy-number button and Facebook name search.

## Update content

Edit service descriptions, prices and contact details in `index.html`. Update the phone number and SMS message in `script.js` as well when changing the contact number. Visual tokens and color previews are in `style.css`.

Color swatches are illustrations, not photographs of Sharlin's work or a confirmed product inventory. No address, opening hours, testimonials or exact Facebook profile URL have been supplied. Facebook therefore links to a name search. Sharlin confirms location, availability, shades and custom-design pricing directly.

## Hosting

This buildless website works on GitHub Pages, Vercel, Netlify or any static host. Publish the repository root. No credentials, external dependencies or build step are required.
